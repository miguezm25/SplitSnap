# SplitSnap

App Android para dividir gastos compartidos con escaneo de recibos mediante OCR.

## ¿Qué hace?
Permite crear grupos, registrar gastos (manualmente o tomando foto a un recibo),
y calcula automáticamente quién le debe a quién.

## Tecnologías
- Kotlin + Jetpack Compose
- Arquitectura MVVM
- Hilt (inyección de dependencias)
- Room (base de datos local)
- CameraX + ML Kit (escaneo de recibos)
- Firebase (sincronización)
